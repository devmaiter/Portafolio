# Portfolio — Julián Osorio

Personal portfolio: who I am, what I build, and how to reach me. Featuring an
animated "hack" intro, a circuit-board background, theme picker, and a
skills-to-projects filter.

## Stack

- [Next.js 16](https://nextjs.org/) (App Router) + React 19
- TypeScript
- Tailwind CSS + [shadcn/ui](https://ui.shadcn.com/)

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Structure

- `app/` — layout, page, and providers
- `components/` — portfolio sections (hero, skills, experience, projects, contact…)
- `components/ui/` — shadcn/ui primitives
